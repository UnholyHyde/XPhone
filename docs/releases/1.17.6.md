# Phone X Game Hub — Android 1.17.6 / Windows 1.4.2

Актуальная пара приложений от 7 ноября 2026. Это тестовая версия проекта для обратной связи, не обещание ускорения любой игры.

## Скачать и обновить

- **Телефон:** `XPhone-Android-1.17.6.apk`, Android 8.0+. Расширенные действия требуют Shizuku и поддержки телефона.
- **Компьютер:** `XPhone-Setup-1.4.2-x64.exe`, Windows 10/11 x64. Установщик включает среду .NET, ADB и scrcpy; устанавливать инструменты разработки не нужно.
- **Проверка файлов:** `SHA256SUMS.txt`.

APK подписан тем же ключом, что опубликованная 1.8.3: обновляйте поверх существующего приложения, без удаления данных. Закройте XPhone на ПК и запустите новый установщик. Первый запуск Shizuku и выдача разрешений остаются действиями пользователя.

## Android 1.17.6

- Самостоятельный игровой хаб: библиотека, локальный профиль игрока, отдельные настройки игр, график доступной истории за семь дней.
- Игровая панель по краям, темы «Графит» / «Стекло», свой цвет и выбор нужных кнопок.
- Открытие двойным нажатием на язычок; удержание переносит его к любой стороне. Приветствие выравнивается по фактическому положению язычка.
- Компактные показатели и отдельное окно FPS / Гц, прозрачность, закрепление, подробности по нажатию. FPS — композиция экрана, не независимые уникальные кадры игры.
- Касания, плавающий микрофон, таймер «Не беспокоить», доступные режимы питания, приложения в окнах и запись экрана — в пределах поддержки устройства и прав.
- Удалено автоматическое отключение Samsung Game Tools, которое вызывало закрытие игры. Защиты при смене режима Samsung во время работающей игры сохранены.
- Возврат из хаба и временное скрытие панели обработаны; игровые окна скрываются внутри самого хаба.

## Windows 1.4.2

- Актуальная версия клиента для работы с Android-хабом и согласования защиты уведомлений перед запуском трансляции.
- USB, беспроводное сопряжение QR/кодом и подключение по адресу локальной сети.
- Самостоятельный установщик с брендированным окном экрана и сохранением сторонних лицензий.

## Проверки и ограничения

Перед выпуском выполнены Android `assembleRelease` / `lintDebug`, проверка подписи APK, 24 существующих Java-набора проверок и Release-сборка Windows. Контрольные суммы при загрузке сверены с GitHub. Проверки сборки не заменяют полноценный прогон установщика на чистой системе.

Основной ручной прогон выполнен на одном устройстве Samsung. Другие модели, слабые телефоны и планшеты требуют тестирования. LAN-переходник аппаратно не проверен. Full Focus экспериментальный и не выделяет игре весь CPU/GPU/интернет. Быстрая запись через Shizuku — без звука; интеграция системной записи пока зависит от прошивки.
